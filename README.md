🎀 Velvet Studio

✨ Descripción

Velvet Studio es una página web creada para mostrar y promocionar productos de moda y vestuario. El proyecto busca presentar los productos de una manera llamativa, organizada y fácil de navegar para los clientes.

🎯 Objetivo

Crear una página web donde los usuarios puedan conocer los productos disponibles, observar sus características y tener una experiencia visual agradable y sencilla.

💻 Características

- 🏠 Página principal.
- 🛍️ Sección de productos.
- 🖼️ Galería de imágenes.
- 🔎 Buscador de productos.
- 👩‍💼 Sección de administrador.
- 📱 Diseño adaptable a diferentes dispositivos.
- ✨ Elementos visuales y animaciones.
- 📋 Información de los productos.

🛠️ Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git bash y GitHub

🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo "index.html" en el navegador.
4. También se puede utilizar Visual Studio Code para editar y ejecutar el proyecto.
